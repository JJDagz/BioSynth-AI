# Research Lab guide

Start with the live site's Academy, open a field note, then inspect the mechanism and variables. Try the Science Lab's evolution and uncertainty models and the Value Lab's freight and purchasing calculators. Use the Portfolio to distinguish available software from scientific evidence. The Roadmap contains a falsifiable next test for every project.

## Source map

- `docs/projects.json`: twelve structured lessons and provenance records.
- `scripts/template.html` and `scripts/render.py`: static HTML generation.
- `docs/assets/models.js`: pure teaching and economic functions.
- `docs/assets/app.js`: progressive enhancement, filtering and scenario export.
- `docs/assets/style.css`: responsive design, reduced motion, focus styles and print rules.
- `docs/index.html`: generated, committed Pages entry point.
- `docs/archive/index-2026-10-29.html`: original page, unchanged and not independently verified.
- `tests/`: automated tests.
- `RESEARCH_LAB_METHODS.md`: formulas and validation protocol.
- `docs/EVIDENCE_AUDIT.md`: evidence availability and negative findings.

Edit the dataset and template, then rerender. Do not hand-edit generated HTML. This is an educational research portfolio, not a supplied implementation of all twelve proposed systems.
