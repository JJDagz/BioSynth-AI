The Feynman method meets scientific discipline

Six moves from idea to evidence

If you cannot explain a mechanism to a motivated beginner, refine the explanation. If you cannot specify what would falsify it, refine the experiment. If you cannot measure full economic costs, do not promise a return.

Cooperation science · Project 01

LOVE Protocol

Experimentally tested
Explain it like I'm 12: Two neighbors share a garden. If both help, both benefit. If one takes everything, the other needs boundaries—but a single mistake should not end the partnership.

The problem

When should an intelligent agent cooperate, punish, or forgive?

How it works

Repeated Prisoner’s Dilemma with C/D moves, a rolling eight-move trust window, tolerance for limited defections, a conditional redemption branch, and exploratory cooperation.

What we know

At 10% action error in the archived synthetic experiment, LOVE scored 2.055 payoff/round and cooperated 66.1%; Tit-for-Tat scored 2.140 and cooperated 49.5%. These are not human-field results.

How value is created

Possible value: fewer broken partnerships, better supplier cooperation, and reduced conflict costs. A dollar claim requires a controlled operational comparison.

Where it breaks

Bait-and-switch or probing opponents can exploit a forgiving rule. More cooperation does not necessarily mean higher individual payoff.

Next falsifiable test

Specify the exact algorithm, compare with strong baselines and adversarial agents, and test whether cooperation rises without unacceptable payoff losses.

Trust & reputation · Project 02

Redemption Amplifier

Hypothesis + toy ablation
Explain it like I'm 12: A library borrower breaks a rule. Instead of a permanent ban, they can regain borrowing privileges by demonstrating reliable behavior—but repeated cheating must remain costly.

The problem

What evidence is enough to restore trust after a violation?

How it works

Historically proposed severity-based penalties, a low-trust rehabilitation trigger, and a 1.5× restoration multiplier. A later simplified LOVE redemption branch was tested separately.

What we know

The historical multiplier system was not fully validated. A later ablation removed a toy recent-cooperation condition and exposed a payoff-versus-cooperation trade-off; the two designs are not identical.

How value is created

Possible value: lower fraud loss, fairer vendor reinstatement, reduced disputes. Quantify recurrence, false rejection, investigation cost, and net benefit.

Where it breaks

An adversary can strategically alternate misconduct with the minimum behavior needed to regain privileges.

Next falsifiable test

Formalize one version; simulate strategic repeat offenders; measure recovery, exclusion, and cumulative exploitation costs.

Scientific automation · Project 03

BioSynth.AI

Prototype
Explain it like I'm 12: A research notebook with a librarian, skeptic, mathematician, and laboratory assistant—but every team member must show their work.

The problem

Can AI research become more reliable through enforced evidence and independent checks?

How it works

Classify claims as sources, computations, assumptions, or hypotheses; generate rival explanations; route problems to simulations; run ethics and quality reviews.

What we know

Recovered Python components implement claim categories, hypothesis templates, ethics triage, basic GAIA scoring, and a LOVE laboratory—not a complete autonomous scientist.

How value is created

Possible value: fewer hours spent gathering, reproducing, and correcting research. Value only verified work completed at a defensible total cost.

Where it breaks

AI agents can repeat one another’s hallucinations; a citation marker does not prove source support.

Next falsifiable test

Build one end-to-end question-to-evidence-to-experiment pipeline; compare factual accuracy and human corrections with a baseline AI workflow.

Decision science · Project 04

APEX Optimization

Framework + prototypes
Explain it like I'm 12: A coach deciding which athlete should do which task while respecting the team’s budget, safety, and schedule.

The problem

Which action produces the greatest defensible value under real constraints?

How it works

Five levers—automation, targeting, faster learning, resource amplification, safeguards—with an explicit objective, measured costs, robustness, and hard constraints.

What we know

Weighted multiobjective optimization is established mathematics. An APEX advantage must be tested against simple and mathematically optimized alternatives.

How value is created

Reduce labor and error, improve allocation; measure the realized benefit net of engineering, oversight, and operating costs.

Where it breaks

Combining arbitrary scoring scales or weights can produce confident but meaningless rankings.

Next falsifiable test

Select one domain, preregister a measurable objective, and benchmark APEX against existing practice.

Network economics · Project 05

FORGE Semiconductor Lab

Implemented research software
Explain it like I'm 12: Roads connect neighborhoods. When one bridge closes, traffic pressure can reach many places. Companies are connected by suppliers in a similar way.

The problem

Where might a semiconductor supply-chain disruption create indirect exposure?

How it works

Financial filing provenance plus an assumed directed network; iterate x(t+1)=(1−d)b+dPx(t) with normalized row sums ≤1 and damping <1.

What we know

The operator converges to a unique numerical fixed point. Its weights and scores are hypothetical exposure assumptions—not calibrated revenue losses, probabilities, or stock forecasts.

How value is created

Support scenario exploration, due diligence, and research prioritization. Economic benefit requires historical calibration and decision comparisons.

Where it breaks

A documented supplier link does not reveal actual dependence, inventory flexibility, or substitution options.

Next falsifiable test

Backtest exposure rankings around documented historical disruptions using only information available before each event.

Applied microeconomics · Project 06

Q-Branch Purchasing

Implemented Python
Explain it like I'm 12: A $75 item that arrives too late can be more expensive than a $90 item ready today.

The problem

What is the true cost of buying something with uncertainty and a deadline?

How it works

Sum item price, shipping, tax, expected repairs, travel, and days-to-use × daily value; estimate deadline risk using a simple delivery-window assumption.

What we know

Opportunity cost is established economics. The code implements the formula; it does not yet demonstrate better real-world purchasing outcomes.

How value is created

Reduce deadline misses, expensive expediting, and poor procurement choices by comparing total economic cost.

Where it breaks

Delivery may not follow a uniform distribution; unknown arrival probability must not be interpreted as zero risk.

Next falsifiable test

Collect observed shipping windows and purchase outcomes, calibrate probabilities, and compare regret with price-only selection.

Quantitative finance · Project 07

OTSA Quant Research

Design; performance unverified
Explain it like I'm 12: A GPS for investing must account for tolls, rough roads, detours, and taxes—not simply choose the shortest-looking route.

The problem

Can adaptive strategies improve after-tax, risk-adjusted investing outcomes?

How it works

Proposed market regime estimation, reinforcement learning, portfolio constraints, tax-lot-aware decisions, and risk-adjusted rewards.

What we know

Archived designs do not establish independently verified, out-of-sample profitable trading. All financial returns remain unproven.

How value is created

Potential value is higher net-of-fees, after-tax utility, not gross backtested return. Validate turnover, slippage, drawdown, and capital requirements.

Where it breaks

Backtest overfitting, look-ahead bias, unrealistic fills, and tax-model errors can create fictional advantages.

Next falsifiable test

Freeze a versioned strategy, use point-in-time data, and compare honestly against low-cost benchmarks over held-out periods.

AI planning · Project 08

Q-Branch Reasoning

Conceptual architecture
Explain it like I'm 12: A detective keeps several suspects and theories open until the evidence rules some out.

The problem

Can exploring competing explanations improve decisions under uncertainty?

How it works

Generate distinct hypotheses, search supporting and opposing evidence, score uncertainty, resolve contradictions, and delay final commitment.

What we know

Parallel classical reasoning is not quantum computation. No quantum speedup or superiority over strong classical baselines is established.

How value is created

Reduce expensive decision errors when uncertainty is consequential; cost must include added inference and review.

Where it breaks

More branches can amplify noise, cost, and correlated model mistakes.

Next falsifiable test

Test against single-path and established planning methods on questions with independently verifiable answers.

Evolutionary game theory · Project 09

Multi-Agent Evolution

Historical claims unverified
Explain it like I'm 12: A village changes when successful behaviors spread and unsuccessful ones disappear—not just because one pair of people behaved well.

The problem

Which cooperation policies survive as competing strategies evolve?

How it works

Model strategy shares with replicator dynamics and/or finite-population mutation and selection; test invasion and population welfare.

What we know

A historical Stag Hunt matrix implies cooperation A outperforms B only when the A-share exceeds 75%; reported rises from roughly 47% require additional mechanisms.

How value is created

Understand persistence of cooperative institutions and competing organizations; avoid converting simulation payoffs directly into dollars.

Where it breaks

Handpicked opponent panels are not evolutionary stability proofs; selection mechanics and random seeds materially affect results.

Next falsifiable test

Reproduce the user-described new negative invasion study from its original ZIP and benchmark it before quoting its results as confirmed.

Ethical optimization · Project 10

Dignity-Constrained Decisions

Conceptual proposal
Explain it like I'm 12: A school cannot simply maximize test scores by excluding students who need the most help. Fairness rules matter.

The problem

How can decision systems optimize outcomes without violating rights?

How it works

Define explicit, justified fairness and consent constraints on resource-allocation optimization; compare feasible policies.

What we know

A historical weighted dignity index was exploratory, not ethically or clinically validated. Human worth is not reducible to productivity.

How value is created

Compare budget and outcome trade-offs while keeping rights and safety non-negotiable. Avoid monetizing human dignity.

Where it breaks

Poorly justified proxies can discriminate or conceal value judgments behind a precise-looking score.

Next falsifiable test

Define constraints with domain experts, simulate counterexamples, and validate distributive impacts before high-stakes use.

Systems engineering · Project 11

Autonomous AI Systems

Architecture + components
Explain it like I'm 12: A restaurant works when the chef, server, cashier, and manager coordinate—but four people checking one order may waste time.

The problem

When do coordinated AI agents outperform simpler tools?

How it works

Task routing, document retrieval, context tracking, authorized tool execution, verification gates, audit logs, and explicit human approvals.

What we know

Multiple agents alone are not a discovery. A valid system benchmark measures correct task completions and full cost.

How value is created

Reduce cost per correctly completed task while respecting privacy, security, and human oversight requirements.

Where it breaks

Errors propagate across agents; tool permissions and auditing may be more important than raw model intelligence.

Next falsifiable test

Evaluate single-model, multi-agent, and human-assisted workflows on an identical internal benchmark.

Operations economics · Project 12

Freight RFQ Automation

Workflow design / pilot candidate
Explain it like I'm 12: Instead of reading every price quote and copying numbers by hand, a careful assistant fills the same comparison sheet and asks the decision-maker to approve.

The problem

Can quotation processing become faster and more accurate without changing business approval rights?

How it works

Ingest quotes from email/PDF, extract structured fields, flag uncertainty, populate one master Excel comparison, send to the business unit, and book only after approval.

What we know

Existing automation techniques; value must be demonstrated through timed real or de-identified cases with an accuracy baseline.

How value is created

Illustration: 400 quotes/month × 11 minutes saved × 12 ÷ 60 × $35/hour = $30,800 annual gross capacity value—not necessarily cash savings.

Where it breaks

Unverified extraction or mistaken approval can cause booking errors; time savings alone may not yield realized dollars.

Next falsifiable test

Build an Excel-preserving minimum viable workflow; run a measured before/after pilot with approval controls.
