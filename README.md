# BioSynth-AI
🌱 BioSynth.AI — A full-stack ethics + intelligence framework combining LOVE Protocol, APEX Optimization Matrix, and Quantum Enhancements for strategic cognition.

## BioSynth Research Lab

An open educational site connecting twelve research systems through simple analogies, transparent mathematical models, evidence disclosures and measurable economic examples. The introductory description above is retained from the original repository; quantum-inspired reasoning is classical reasoning, not a demonstrated quantum speedup.

**Website source:** [`docs/index.html`](docs/index.html). Intended GitHub Pages address: https://jjdagz.github.io/BioSynth-AI/ — deployment must be verified separately; source being pushed does not guarantee Pages is enabled.

### Local checks

Requires Node.js 20+ and Python 3.9+, with no production dependencies.

```sh
python3 scripts/render.py
python3 scripts/render.py --check
node --test tests/*.test.cjs
python3 scripts/check_site.py
```

Serve the `docs/` folder using a static server. Lessons work without JavaScript; live models and filtering use small local scripts. No API key, analytics or third-party font is required.

### What is included

Home, Research Academy, Scientific Laboratory, Economic Value Laboratory, Research Portfolio, Implementation Roadmap and Open Research. Twelve field notes each include analogy, problem, three mechanism steps, equation, variable definitions, worked example, achievement, evidence gap, failure mode, economic channel, baseline and falsification test. Interactive population, probability, purchasing and freight models are teaching tools, not project-level experimental results.

### Scientific status

The original page is preserved verbatim in [`docs/archive/`](docs/archive/index-2026-10-29.html). Reported LOVE cooperation/payoff trade-offs and the newer user-reported unfavorable evolutionary study remain distinct. Original scripts, seeds and outputs are needed for independent reproduction. FORGE outputs are illustrative exposure scores. OTSA profitability is unverified. Freight value is a scenario, not achieved cash savings. See the audit before citing any research result.

### GitHub Pages

Use repository **Settings → Pages → Deploy from a branch → main → /docs → Save**. The `.nojekyll` marker keeps this a plain static site. A separate CI workflow validates the committed HTML and models on pushes and pull requests. Check the Pages deployment in Actions and the public page before claiming success. No force push or existing research deletion is required.
